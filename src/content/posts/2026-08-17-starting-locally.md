This is a first post so the writing index is not empty.

The site runs on Eleventy. Pages and posts are Markdown. From the repo root:

```
npm install
npm run dev
```

Then open [http://localhost:4000](http://localhost:4000).

When the local preview looks right, we can rename the GitHub repo to `pratikyadav33.github.io`, make it public, and turn on GitHub Pages.
